# LumiRead

> 打破文字边界，你的专属 AI 互动视觉小说引擎。

一款基于原生 Android (Jetpack Compose) 打造的沉浸式 AI 视觉小说阅读器。支持导入 TXT 与 EPUB 长篇小说，通过接入智谱 GLM 大模型进行深度语义解析，实时调用图像引擎生成 16:9 剧场级动漫场景与固定 Seed 的一致性角色立绘。采用全局单队列与超时熔断机制，搭配悬浮毛玻璃 UI 与呼吸浮动动画，为你带来无缝、丝滑、无限流的 Galgame 体验。你的每一本小说，都可以是一部专属的动漫。

## 核心特性

- 📖 支持 TXT / EPUB 智能章节解析
- 🎬 16:9 剧场级原生 Compose 沉浸式舞台
- 🧠 智谱大模型上下文语义分析，无缝预加载
- 🎨 AI 实时生图与固定 Seed 角色一致性控制
- 🛡️ 协程单队列调度，防限流与超时熔断
