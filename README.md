# LumiRead

> 打破文字边界，你的专属 AI 互动视觉小说引擎。

一款基于原生 Android (Jetpack Compose) 打造的沉浸式 AI 视觉小说阅读器。支持导入 TXT 与 EPUB 长篇小说，通过接入智谱 GLM 大模型进行深度语义解析，实时调用图像引擎生成 16:9 剧场级动漫场景与固定 Seed 的一致性角色立绘。采用全局单队列与超时熔断机制，搭配悬浮毛玻璃 UI 与呼吸浮动动画，为你带来无缝、丝滑、无限流的 Galgame 体验。你的每一本小说，都可以是一部专属的动漫。

## 核心特性

- 📖 支持 TXT / EPUB 智能章节解析
- 🎬 16:9 剧场级原生 Compose 沉浸式舞台
- 🧠 智谱大模型上下文语义分析，无缝预加载
- 🎨 AI 实时生图与固定 Seed 角色一致性控制
- 🛡️ 协程单队列调度，防限流与超时熔断

## v0.4.0-alpha 更新

- **双层主题系统**：全局 App 主题（跟随系统 / 浅色 / 深色）与阅读器独立主题（白 / 米黄 / 护眼绿 / 深灰 / 纯黑）分离，使用 DataStore 持久化，颜色统一收敛到 `ui/theme/Color.kt`。
- **液态玻璃**：底部导航、阅读器顶栏、控制台、VN 对话框全部使用 Haze 2.0 Glass（模糊 + 低透明度底色 + 边缘高光描边）。
- **控制台重写**：全屏 Box + 0.4 遮罩 + 贴底玻璃面板，彻底移除 ModalBottomSheet。
- **TXT 解析**：复合标题正则 + Ghost-chapter 合并 + 段落 `\n\n` 重整。
- **EPUB 解析**：TOC（toc.ncx / nav.xhtml）与 Spine 交叉验证，目录外的碎片文件并入上一章。
- **API 极简配置**：Key 硬编码在 `data/ApiConfig.kt`，设置页不再提供输入框。
